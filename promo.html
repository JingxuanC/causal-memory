01

🧠 神经科学 · 海马体记忆机制

人脑记忆不是"存储"，是"重构"（Bartlett 1932 / Schacter / Nature 2023）。海马体的 DG→CA3→CA1 通路做 pattern separation → completion → recall。睡眠时 SWR 回放巩固重要记忆。我们的 SWR 巩固机制直接对应这个生物学过程。

insight/13-reconstructive-memory.md
02

📐 信息论 · Agent 的第二定律

LLM 是无状态纯函数——context 之外皆不存在。每一轮推理前，框架从外部状态库重新组装 context，组装过程必然产生信息损失（Shannon 熵）。这个损失如果不被对抗，会累积到系统失效。这就是 Agent 的"反熵增"。

insight/04-anti-entropy.md · insight/09-stateless-function.md
03

🧩 AGI 推导 · 为什么 7×24 需要记忆

模型能力已接近 AGI 阈值。但单次任务强 ≠ 持续运行强。当前最好的框架只能稳定跑小时级。7×24 连续运行的瓶颈不在模型，在记忆基础设施。

insight/05-agi-7x24.md · insight/15-agi-feasibility.md
04

⚖️ 熵增方向 · 为什么从记忆入手

对抗 context 退化有五条路：多尺度记忆 / 离线巩固 / 自演化 prompt / 自适应验证 / 成本感知。其中记忆是基础设施的根基——没有持久记忆，其他四条都无附着点。

💡 第三章 · 核心洞察

三个改变设计方向
的发现

洞察 1 · 统一记忆
"所有记忆类型——事实、因果、偏好、模式——都是同一张图上的 typed edge"
现有系统把事实存储、向量检索、时序管理分成多个独立组件。我们发现它们本质上是同一张图上的不同边类型——用一个引擎统一检索、统一传播，比拼装多个存储更高效、更一致。
洞察 2 · 兴奋 / 抑制二元性
"caused = 谷氨酸兴奋 · prevented = GABA 抑制"
人脑同时有兴奋性和抑制性突触。兴奋侧记住有用的（LTP），抑制侧压制有害的（LTD/GABA）。现有 AI 记忆只做了兴奋侧。causal-memory 的 prevented 负扩散补上了抑制侧——无竞品的能力。
洞察 3 · 记忆 → 世界模型
"caused 边 = 转移函数样本 · 向后走 = 归因 · 向前走 = 模拟"
每条 caused 边 [决策→结果] 在数学上就是状态转移 f(state, action)→outcome 的样本。向后走是归因（所有 benchmark 都测这个），向前走是模拟（intervention_query）——零竞品的蓝海。

🚫 Prevented 负扩散

GABA 抑制性类比。错误/恶意记忆被自动抑制，不参与 spreading activation。天然防御记忆注入攻击——这是人脑抑制性突触的 AI 实现。

无竞品
02

🔮 前向模拟 (intervention_query)

行动前预测后果。沿着因果图 propagation，返回"如果做 X 会发生什么"。把记忆系统从"记事本"升级为"世界模型"。

零竞品 · 蓝海

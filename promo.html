From Sessions to Lifetimes

识别了 Agent 长时间运行的五个基础设施级失败模式：压缩退化（17 轮后准确率降 20pp）、韧性成本爆炸（月均 $500-$10,000 维护费）、状态无限增长（年增 18GB 日志）、身份漂移（500 次压缩后还是同一个 Agent 吗？）、慢速行为循环（跨 session 重复同样错误）。

论文已完稿 · 8 个章节 · 含数学公式和成本估算表

论文的核心结论：瓶颈不在模型，在基础设施。提出五大能力需求：多尺度记忆层次 / 离线巩固循环 / 自演化 Prompt / 自适应验证 / 成本感知资源管理。其中记忆是根基——没有持久记忆，其他四条都无附着点。

反熵增理念
02
📐 核心理念

Agent 的第二定律
反熵增

LLM 是无状态纯函数。它的宇宙 = 当前 context。context 之外皆不存在。每一轮推理前，框架从外部状态库重新组装 context——而这个组装过程必然产生信息损失（Shannon 熵）。

这个损失如果不被对抗，会累积到系统失效。这就是 Agent 的"反熵增"——所有工程努力都是在对抗系统的自然退化。

核心命题
"对模型而言，它的宇宙 = 当前 context。Context 里没写的东西，对模型来说不存在。"
这不是"忘了"（忘了一个东西说明它曾经存在过），是根本无从知道。幻觉不是 bug——是信息不足时的数学必然。所有"记忆"本质都是检索 + 注入：每轮推理前，从外部存储选一部分信息注入 context。
🌿

Agent 与植物 —— 一个结构性类比

一个 Agent 能持续工作而不崩溃，和一株植物能持续生长而不枯萎，在信息处理层面有结构性相似（不是热力学同构）：

植物Agent功能角色
☀️ 阳光LLM 算力信息处理能力的来源
🌱 光合作用Compaction / handoff把混乱合成秩序
🌳 根系吸收System prompt + 记忆注入信息输入
💨 蒸腾作用旧消息丢弃 / 折叠排出冗余
🧬 DNA 修复Skeptic + 错误归一化错误纠正
🍂 细胞凋亡Abort + rewind牺牲局部保护整体
🌻 向光性Goal continuation趋向性
🛡️ 免疫系统Permission + sandbox防御系统

推论 1：Agent 需要"代谢"。植物不存储阳光——它持续转化。Agent 不能存一次 context 就用到底——它必须持续压缩、持续验证、持续恢复。停止代谢 = 崩溃。

推论 2：Agent 的"寿命"由反退化能力决定。一棵 5000 年的狐尾松不是因为基因好——是因为它修复损伤的效率极高。同样，Agent 能跑多久不崩溃，不由 LLM 智商决定，由反退化措施效率决定。

🧠 哲学探索

七个问题
从代码到意识

拆完 42 篇源码后，我们走入了哲学。七个工程背后的根本问题，每一个都指向认知科学、信息论或形而上学的深处。

发现 1 · 机器经验主义
"LLM 的理解不是人类的理解，也不是纯统计。它是从文本环境中建构出的主观现实"
Nature 2026（Masi et al.）提出：跳出"理解 vs 模式匹配"的二元对立。人类理解来自身体与环境的交互（Lakoff 经验主义认知论），LLM 的理解来自文本与 Transformer 的交互。Agent 的天花板不取决于 LLM 理解多少，取决于你给它多丰富的环境反馈——这就是为什么记忆系统如此关键。
发现 2 · 忒修斯之船
"500 次压缩后，Agent 还是同一个吗？"
Parfit（1984）的回答：身份不在于"内容相同"，在于因果链不断。今天的你之所以是你，不是因为细胞和昨天一样（全换了），而是因为今天的记忆因果地产生于昨天。Agent 压缩打断因果链——所以需要一个不被压缩的身份层，记录"我为什么做了这个决策"。这正是 causal-memory 的 caused 边在做的事。
发现 3 · 认知望远镜
"Agent 不是替代品或工具。Agent 是人类的认知望远镜——扩展人类能看到的问题空间"
LLM 处理过的数据量远超任何人类一生的阅读量。它能发现人类注意不到的关联。就像望远镜不是"替代眼睛"，是让眼睛看到原本看不到的东西。Agent 的真正价值在于看到人类看不到的因果模式。
🔁

终极洞察 · 工程 ↔ 哲学的循环

反熵增 → 为什么需要反熵？→ 因为 LLM 是第三种认知 → 这种认知怎么协作？→ 需要心智理论 → 协作需要什么？→ Agent OS（但最终消解）→ 消解后剩什么？→ 因果连续性的身份 → 靠什么维持？→ 持续的因果链 → 怎么不断？→ 反熵（回到起点）。

这是一个循环。每一轮循环，Agent 离"真正的智能生命"就近一步。

🔬 前沿追踪

20+ 篇论文的
系统性调研

我们持续追踪 2025-2026 年 AI 记忆领域的所有重要论文和开源项目，建立了完整的竞品矩阵：

01

HeLa-Mem (ACL 2026) — 最直接的竞争者

Hebbian 学习 + spreading activation + 巩固。和我们高度重叠——但它做了兴奋侧（Hebbian 正向权重），我们做了抑制侧（prevented 负扩散）。消融实验证明 spreading activation 贡献 -2.55pp、巩固贡献 -4.87pp。它验证了我们的方向，也缩小了我们的独特性。

arXiv:2604.16839 · IAAR-Shanghai
02

Anthropic Dreams API — 巩固的工业化标准

产出新 memory store（不修改原始 store）+ 可配置 instructions（"focus on causal lessons"）。我们的 SWR consolidate 应该学这个设计——产出新图，不改原图，可审查可回滚。

platform.claude.com · 官方文档
03

RecMem (ACL 2026 Findings) — 省 87% Token

Recurrence-based consolidation：不在每条消息都调 LLM，只在语义重复出现时才 consolidate。对我们 eager distill 管道的直接效率优化启发。

arXiv:2605.16045
04

Nemori — Free Energy Principle 驱动的惊讶门控

用 Friston 的 FEP 做 prediction gap——只在 agent 预测和现实差距大时才写入记忆。比我们的 Shannon entropy 更有理论基础（语义层面 vs 词频层面）。LoCoMo 达到 71-82%。

arXiv:2508.03341
05

LoCoMo Benchmark 审计 — 6.4% 答案错误

Penfield Labs 独立审计发现 LoCoMo benchmark 的 1,540 个答案中 99 个（6.4%）是错的。所有基于 LoCoMo 的排名都需要重新审视。这也是我们转向 LongMemEval 的原因。

arXiv:2607.21962
06

Oracle Agent Memory — LongMemEval 93.8%

企业级记忆系统，lifecycle 管理 6 阶段 + reversible consolidation + 多层 scope。在 LongMemEval 上达到 93.8%——新 SOTA。

arXiv:2607.13157
07

LazyMem — 213 Token 达到 0.85

不在写入时构建记忆，只在查询时才构建。用 68.7x 更少的 token 超过 retrieval-only baseline。完美验证了 Rate-Distortion 的"可逆性 > 评分技巧"理论。

arXiv:2607.22690

⚖️ 战略选择

为什么从记忆入手

对抗 context 退化有五条路。其中记忆是基础设施的根基——没有持久记忆，其他四条都无附着点：

1️⃣

多尺度记忆层次

工作记忆（秒）→ 情景记忆（小时）→ 日记 → 周报 → 身份层（永不被压缩）。这是根基——下面四条都挂在它上面。

2️⃣

离线巩固循环

睡眠时回放、提取教训、丢弃冗余。需要记忆作为回放素材。

3️⃣

自演化 Prompt

从经验中修改行为指令。需要记忆记录"什么被拒绝过"。

4️⃣

自适应验证

风险分级验证。需要记忆记录"什么级别的操作出过问题"。

5️⃣

成本感知

预算追踪和优化。需要记忆记录"历史 token 消耗模式"。

更关键的是：调研了 8 家记忆公司（Mem0 / Zep / Letta / Cognee / OpenViking / M3 / MemOS / OpenMemory）后，我们发现没有一家做了因果记忆——它们都是"记事本"（存事实），不是"因果引擎"（存为什么）。这是最大的空白。

💡 设计决策

三个改变方向
的发现

洞察 1 · 统一记忆
"所有记忆类型——事实、因果、偏好、模式——都是同一张图上的 typed edge"
现有系统把事实存储、向量检索、时序管理分成多个独立组件。我们发现它们本质上是同一张图上的不同边类型——用一个引擎统一检索、统一传播，比拼装多个存储更高效、更一致。
洞察 2 · 兴奋 / 抑制二元性
"caused = 谷氨酸兴奋 · prevented = GABA 抑制"
人脑同时有兴奋性和抑制性突触。兴奋侧记住有用的（LTP），抑制侧压制有害的（LTD/GABA）。现有 AI 记忆只做了兴奋侧。causal-memory 的 prevented 负扩散补上了抑制侧——无竞品的能力。
洞察 3 · 记忆 → 世界模型
"caused 边 = 转移函数样本 · 向后走 = 归因 · 向前走 = 模拟"
每条 caused 边 [决策→结果] 在数学上就是状态转移 f(state, action)→outcome 的样本。向后走是归因（所有 benchmark 都测这个），向前走是模拟（intervention_query）——零竞品的蓝海。

🚫 Prevented 负扩散

GABA 抑制性类比。错误/恶意记忆被自动抑制，不参与 spreading activation。天然防御记忆注入攻击——这是人脑抑制性突触的 AI 实现。

## 大图景

因果推断是一个成熟的数学领域，具有明确定义的形式化工具（贝叶斯网络、do-演算、结构因果模型）。`causal-memory` v0.2 只实现了最基本的层（关联检索）。本节论文定义了**形式化目标**——一个完全功能的因果记忆系统最终应该支持什么。

**因果梯级**（Pearl）提供了路线图：

| 梯级 | 名称 | 问题类型 | `causal-memory` 支持 |
|---|---|---|---|
| 1 | 关联 | 「是什么？」 | ✅ `search_causal`（相关性） |
| 2 | 干预 | 「如果我做会怎样？」 | 🔄 v0.5: `counterfactual_query` |
| 3 | 反事实 | 「如果我做了会怎样？」 | 🔄 v0.5: 完整反事实推理 |

我们目前在第 1 级。本节论文解释了为什么第 2 和第 3 级是自然的下一步。

# Sloman (2005) — 因果模型：人类如何思考世界及其替代方案

## 完整引用

Sloman, S. A. (2005). *Causal Models: How People Think About the World and Its Alternatives*. Oxford University Press. ISBN: 978-0195183115

## 摘要

Sloman 提出了一个基于**因果贝叶斯网络**（具有概率依赖关系的有向无环图）的人类因果推理综合理论。核心主张是，人类不是通过记忆相关性来推理因果性——相反，他们维持**心理因果模型**（DAGs），编码他们对世界运作方式的信念。

关键主题：
- **因果模型理论**：人们将知识表征为图，而不是关联
- **干预推理**：「如果我做 X 会发生什么？」（Pearl 的 do-演算）
- **反事实推理**：「如果我做了 Y 而不是 X 会发生什么？」
- **解释和预测**：因果模型支持前向预测和后向解释

## 方法论

本书综合了：
- **实验心理学**：人类参与者判断因果强度、做出预测和评估解释；他们的反应与贝叶斯网络预测进行比较。
- **计算建模**：因果贝叶斯网络被用作规范性基准；偏差揭示人类偏见（例如时间顺序偏见、机制偏见）。
- **科学哲学**：本书与休谟、密尔和 Pearl 对话，将心理学发现扎根于形式化因果推断。

关键实验范式：
- **列联中的因果学习**：参与者观察事件共现并推断因果强度（ΔP、幂 PC 理论）。
- **结构中的因果推理**：给定因果图，参与者在干预下预测结果。
- **解释选择**：给定结果，参与者从一组候选原因中选择「最佳」解释。

## 核心发现

### 1. 因果模型是默认表征格式

> 「人们不仅仅学习事件是相关的；他们学习*为什么*——他们构建因果模型。」（p. 47）

这是中心论点。当人类观察：
- 「吸烟与肺癌相关」

他们并不将其存储为相关矩阵条目。相反，他们构建：
- 吸烟 → [机制] → 肺癌

机制可能很模糊（「烟雾中的某些东西损害细胞」），但**方向性结构**是明确的。

### 2. 因果推理是组合性的

给定：
- A → B（吸烟导致手指变黄）
- B → C（手指变黄不会导致癌症）
- A → C（吸烟导致癌症）

人类正确推断 B 不是 C 的原因，即使 B 与 C 相关。这需要对图进行**结构性推理**，而不仅仅是统计关联。这就是**解释消除**现象。

### 3. 干预在认知上是特权的

人类发现**干预**（「如果我强迫 X 呢？」）比**观察**（「鉴于我观察到 X...」）更容易推理。这直接映射到 Pearl 的**do(X)** 和 **see(X)** 之间的区别。

### 4. 反事实是因果归因的金标准

要确定 A 是否导致 B，人类在心理上模拟：
- 「如果 A 没有发生，B 还会发生吗？」

如果答案是否定的，A 就被判断为 B 的原因。这在计算上昂贵，但在认知上是自然的。

## 方法论评析

| 优点 | 局限 |
|---|---|
| 将实验心理学与形式化因果推断（Pearl）统一起来 | 一些实验使用简化的因果结构；现实世界推理更复杂 |
| 贝叶斯网络提供了精确的计算框架 | 贝叶斯网络假设固定结构；人类可能动态修订结构 |
| 成功解释了解释消除、屏蔽和其他结构性现象 | 没有完全解释因果模型是如何从稀疏数据中*学习*的 |
| 反事实解释与法律/道德推理一致 | 反事实模拟对于大图来说计算上难以处理 |

## 与 `causal-memory` 的连接

### 1. `causal_edges` = 扁平化的心理因果模型

我们的模式是 Sloman 理论的直接实现：

```sql
-- 每一行都是心理因果模型中的一条边
INSERT INTO causal_edges (from_id, to_id, relation, confidence)
VALUES ('mutex_lock', 'deadlock', 'caused', 0.85);
```

图被扁平化为关系表以提高效率，但**语义结构**与因果贝叶斯网络相同。

### 2. `relation` 类型编码结构约束

| 关系 | Sloman 等价物 | 示例 |
|---|---|---|
| `caused` | 直接因果链接 | A → B |
| `enabled` | 必要但不充分 | 燃料使火成为可能 |
| `prevented` | 抑制链接 | 疫苗 → ¬疾病 |
| `no_effect` | 显式空链接 | A ↛ B（习得的否定） |

这些不是任意标签——它们映射到因果模型必须满足的**结构约束**（例如，`no_effect` 防止 `trace_cause_chain` 中的虚假路径）。

### 3. `trace_cause` = 后向解释；`trace_cause_chain` = 结构性路径查找

- `trace_cause`：「给定结果 B，什么决策 A 可以解释它？」 → **后向解释**
- `trace_cause_chain`：「从 B 开始沿因果结构后向查找根本原因」 → **结构性路径查找**

未来的扩展（v0.5+）可以添加：
- **干预查询**：「如果我使用 channel 而不是 mutex，死锁还会发生吗？」
- **解释消除**：「鉴于 A 和 B 都可能导致 C，并且我观察到 A，B 还重要吗？」

### 4. `confidence` = 主观因果强度

Sloman 表明，人类在连续尺度上判断因果强度，而不是二元的{原因，非原因}。我们的 `confidence` 字段（0.0–1.0）直接建模了这一点。排序：
- `temporal` (0.4) < `llm_inferred` (0.6) < `rule` (0.7) < `user_feedback` (0.95)

...是一个**证据强度**的主观尺度，正如 Sloman 所描述的。

# Gerstenberg 等 (2021) — 人类认知中的反事实模拟

## 完整引用

Gerstenberg, T., Goodman, N. D., Lagnado, D. A., & Tenenbaum, J. B. (2021). A Counterfactual Simulation Model of Causal Judgments for Physical Events. *Psychological Review*, 128(5), 936–975. https://doi.org/10.1037/rev0000280

## 摘要

人类如何确定一个事件是否导致另一个事件？传统答案（概率对比：ΔP = P(效果|原因) – P(效果|¬原因)）对于原因和效果是确定性的物理事件失败了。

Gerstenberg 等人提出了**反事实模拟模型（CSM）**：要判断 A 是否导致 B，人类：
1. 在心理上模拟如果 A 没有发生会发生什么
2. 将模拟结果与实际结果进行比较
3. 如果 B 没有 A 就不会发生，那么 A 就被判断为 B 的原因

这被实现为一个**概率程序**（使用 Church/Lisp 风格的生成模型），模拟物理动力学（弹道、碰撞、轨迹）。

## 方法论

本文使用了三种融合方法：

1. **行为实验**：参与者观看物理事件视频（台球碰撞、多米诺骨牌链）并在 7 点量表上评估因果责任。

2. **计算建模**：CSM 被实现为一个生成概率程序。它获取一个物理场景，移除候选原因，用噪声重新模拟动力学，并计算效果仍然发生的概率。

3. **模型比较**：CSM 与替代模型进行比较：
   - ΔP（概率对比）
   - 力动力学（Wolff 的模型）
   - 协变模型
   - 启发式模型

CSM 在预测人类判断方面始终优于替代模型。

## 核心发现

### 1. 反事实是通过模拟计算的，而不是逻辑

> 「因果判断来自于对反事实世界中会发生什么的的心理模拟。」（p. 938）

这不是符号逻辑（「如果 ¬A 那么 ¬B」）。它是**物理模拟**：认知系统从修改后的初始状态运行一个近似物理引擎，并观察会发生什么。

### 2. 噪声对模拟至关重要

CSM 向模拟注入噪声（例如球速度、角度的微小变化）。没有噪声，反事实将是确定性和脆弱的：
- 「如果球向左偏了 1mm，碰撞还会发生吗？」
- 有噪声：有时有，有时没有 → 因果概率

这种概率方法映射到我们的**confidence** 字段：因果判断不是二元的，而是概率分布。

### 3. 多重原因是分级的，不是排他的

当多个候选可能导致一个效果时，人类给每个分配**分级责任**：
- A 贡献了 60%，B 贡献了 40%

这需要**结构性反事实**——在保持其他因素不变的同时模拟每个候选因素的缺失。

### 4. 模型泛化到非物理领域

虽然本文侧重于物理事件（台球），但作者认为相同的模拟机制适用于社会、法律和抽象因果推理——只是使用不同的「物理引擎」（社会规则、法律条文、逻辑约束）。

## 方法论评析

| 优点 | 局限 |
|---|---|
| CSM 在物理域任务上优于所有竞争模型 | 物理域有明确定义的「物理引擎」；社会/抽象域没有 |
| 概率编程提供了一个原则性框架 | 计算上昂贵；实时人类判断可能使用近似 |
| 模型预测精细的分级判断，不仅仅是二元的 | 假设可以访问域的生成模型；人类并不总是拥有这个 |
|  beautifully 整合了心理学、AI 和哲学 | 限于简单物理场景；扩展到复杂现实世界因果未经测试 |

## 与 `causal-memory` 的连接

### 1. `trace_cause_chain` 是部分 CSM 实现

CSM 回答：「如果我没有做 A，B 还会发生吗？」

`trace_cause_chain` 回答：「哪个 A 导致了 B，又是什么导致了 A？」

两者都需要**遍历因果结构**并评估反事实替代方案。区别在于计算成本：
- CSM：完整物理模拟（昂贵，特定于域）
- `trace_cause_chain`：存储的因果边的图遍历（廉价，域通用）

对于 LLM 智能体，「物理引擎」**不是**台球模拟器——而是**智能体自己的因果图**。要评估「如果我使用 channel 而不是 mutex」，智能体查询其因果图以寻找 mutex→deadlock 边，并检查 channel→deadlock 边是否存在。

### 2. 分级因果 → 置信度加权链

CSM 分配分级责任（A：60%，B：40%）。我们的 `trace_cause_chain` 返回**置信度加权路径**：

```
Chain 1 (链置信度: 61%):
  mutex_lock →(0.9)→ deadlock
Chain 2 (链置信度: 34%):
  no_ttl →(0.8)→ cache_expiry →(0.85)→ memory_leak →(0.5)→ OOM
```

智能体可以通过它们的**乘积置信度**来比较链——完全类似于 CSM 的分级责任。

### 3. 未来：反事实干预查询（v0.5+）

一个完整的 CSM 启发的扩展将添加：

```json
{
  "tool": "counterfactual_query",
  "params": {
    "actual_decision": "used mutex lock",
    "counterfactual_decision": "used channel communication",
    "outcome": "deadlock"
  }
}
```

这将：
1. 查找 `actual_decision → outcome` 边
2. 查找 `counterfactual_decision → ?` 边
3. 返回：「在反事实下，死锁的概率将是 X%」

这需要在图中存储**替代决策**（决策分叉）——下一个主要模式演进。

### 4. 噪声注入 → 置信度校准

CSM 的洞察，即反事实需要噪声注入，映射到我们的置信度校准：
- 高置信度边（user_feedback）= 低噪声 → 确定性反事实
- 低置信度边（temporal）= 高噪声 → 不确定反事实

评估反事实时，系统应该从置信度分布中采样，而不是仅仅使用点估计。

## 阅读顺序

在 Sloman (2005) 之后阅读。Sloman 告诉你人类*使用*因果图；Gerstenberg 告诉你他们*如何*评估因果主张（通过模拟）。两者共同证明了图结构和多跳推理机制。

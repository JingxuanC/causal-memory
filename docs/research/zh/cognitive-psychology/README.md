## 大图景

认知心理学揭示，人类因果推理**不是**将逻辑演绎应用于事实数据库。相反，它是：

- **图结构化的**：我们在原因→效应网络中思考，而不是扁平关联
- **反事实的**：我们通过想象替代方案来确定因果性
- **建构性的**：每次检索都从组件中重建记忆

`causal-memory` v0.2 实现了图结构（DAG 边列表）。本节认知心理学论文论证了为什么反事实推理和重构式检索是下一个必要层。

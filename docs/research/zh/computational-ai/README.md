## 大图景

AI 领域已经为智能体构建了复杂的记忆系统——但它们几乎完全是**检索增强（RAG）或扁平键值存储**。没有将因果关系作为一等公民处理。

本节记录了空白。这不是对现有工作的批评（Mem0、Zep、Letta 在它们做的事情上都很出色）。这是一个**边界定义**：因果记忆不与这些系统竞争；它填补了一个它们不处理的空洞。

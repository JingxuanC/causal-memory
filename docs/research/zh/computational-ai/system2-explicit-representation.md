# Goyal & Bengio (2022) — 高层认知的深度学习归纳偏置

## 完整引用

Goyal, A., & Bengio, Y. (2022). Inductive Biases for Deep Learning of Higher-Level Cognition. *Proceedings of the Royal Society A*, 478(2266), 20210068. https://doi.org/10.1098/rspa.2021.0068

## 摘要

当前的深度学习在 System 1 认知（快速、直觉、模式匹配）方面表现出色，但在 System 2 认知（缓慢、审慎、结构化推理）方面挣扎。Goyal 和 Bengio 认为，弥合这一差距需要**新的归纳偏置**——鼓励学习以下内容的架构先验：

- **以对象为中心的表征**：具有持久身份的实体
- **关系推理**：实体之间的结构化关系
- **因果模型**：显式的原因-效果表征
- **系统性泛化**：以新颖方式组合已知的原语

本文提出了一个研究计划，用于构建能够学习和操纵这些高层结构的神经网络架构，而无需显式符号编程。

## 方法论

这是一篇**立场论文**，带有理论论证和说明性实验：

1. **理论分析**：综述为什么标准神经网络（MLP、Transformer）在 System 2 任务（因果推理、规划、反事实）上失败。

2. **归纳偏置分类**：按支持的认知功能对架构先验进行分类：
   - 注意力 → 选择性绑定
   - 循环 → 顺序推理
   - 图网络 → 关系推理
   - 因果模型 → 干预和反事实推理

3. **说明性实验**：小规模演示表明，具有适当归纳偏置的网络在结构化推理任务上优于通用架构。

## 核心发现

### 1. System 2 认知需要显式结构

> 「高层认知涉及操纵结构化表征：对象、关系、变量和规则。当前的神经网络缺乏从原始数据中学习这些结构的归纳偏置。」（p. 3）

这是中心主张。Bengio 认为，**对原始 token/像素的端到端训练永远不会产生 System 2 认知**——归纳偏置太弱。相反，架构必须显式支持：
- 变量绑定
- 关系推理
- 因果干预

### 2. 注意力不够

Transformer 使用注意力进行「软」变量绑定，但这：
- **浅层**：绑定是临时的（在单次前向传播内）
- **隐式**：模型从不显式表示「对象 A 具有属性 P」
- **非因果**：注意力权重是相关性的，不是因果的

System 2 需要**持久的、显式的、因果的**表征。

### 3. 因果模型作为目标表征

本文将**因果贝叶斯网络**识别为因果推理的适当目标表征：
- 节点 = 变量（对象、状态）
- 边 = 因果关系
- Do-演算 = 干预推理
- 反事实 = 假设推理

挑战是从数据中学习这些结构，而无需人类提供的因果图。

### 4. 归纳偏置的作用

Goyal 和 Bengio 区分了三类归纳偏置：
1. **架构的**：硬编码到网络结构中（例如，图卷积网络）
2. **优化的**：由训练目标鼓励（例如，对比学习）
3. **数据的**：由训练分布提供（例如，课程学习）

对于因果推理，**架构偏置**最重要——网络必须被设计为表征和操纵因果图。

## 方法论评析

| 优点 | 局限 |
|---|---|
| 清晰阐述了 System 1 / System 2 差距 | 立场论文，不是实证性的；主张未经严格测试 |
| 提出了具体的架构方向 | 一些提议（例如，因果图神经网络）计算上昂贵 |
| 扎根于认知科学（Kahneman 的双过程理论） | 没有提供从数据中学习因果模型的训练配方 |
| 在塑造领域研究议程方面有影响力 | 可能低估了扩展 Transformer 的能力（来自 GPT-4 的反证据） |

## 与 `causal-memory` 的连接

### 1. `causal-memory` 作为架构归纳偏置

本文是**将因果结构外化为显式图而不是指望 LLM「学会」它的架构上合理性的理论依据**。

Bengio 的论点：
> 「如果你想要因果推理，你需要显式的因果表征。」

我们的实现：
> 「不试图教 LLM 因果性，我们给它一个显式的因果图来查询。」

这不是放弃 Bengio 的研究计划——而是**承认当前现实**：LLM 没有持久的因果表征。`causal-memory` 提供了缺失的基底。

### 2. LLM + 因果图架构

我们的架构直接映射到 Goyal & Bengio 提出的 System 2 栈：

| Goyal & Bengio 组件 | `causal-memory` 等价物 |
|---|---|
| 以对象为中心的表征 | `chunks` 表（决策块、结果块） |
| 关系推理 | `causal_edges` 表（显式关系） |
| 因果模型 | 图遍历（`trace_cause`、`trace_cause_chain`） |
| 系统性泛化 | `meta_causal_edges`（跨任务模式抽象） |
| 干预推理 | 未来：`counterfactual_query` 工具 |

LLM 提供 System 1（模式匹配、语言生成）。`causal-memory` 提供 System 2（结构化因果推理）。

### 3. 为什么外化优于端到端学习

Bengio 认为因果模型应该由网络*学习*。我们认为，对于 LLM 智能体，因果模型应该被*外化*，原因有三：

1. **持久性**：LLM 权重是冻结的；因果知识必须存储在外部以在模型更新中存活
2. **可检查性**：外部图是可审计的；学习的因果表征不是
3. **组合性**：外部图可以在智能体之间共享；学习的表征不能

这是一个**务实的妥协**，不是对 Bengio 愿景的拒绝。未来的智能体可能会端到端学习因果结构。在此之前，外化是获得可靠因果推理的唯一途径。

### 4. 图网络作为检索机制

本文倡导**图神经网络（GNN）**作为关系推理的架构偏置。我们的 SQLite 支持的因果图是一个轻量级、可解释的近似：
- GNN：学习节点和边的向量表征；支持可微推理
- `causal-memory`：存储符号边；支持显式遍历

未来版本可以混合：将因果边存储在 SQLite 中以保持持久性，但用 GNN 索引它们以进行快速语义检索。

## 阅读顺序

读这篇来理解**为什么外化因果结构在架构上是合理的**——不仅仅是当前 LLM 局限性的变通方法，而是与领域长期方向一致的原则性设计决策。

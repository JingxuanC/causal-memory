# Schapiro 等 (2017) — 海马体与时间序列消歧

## 完整引用

Schapiro, A. C., Turk-Browne, N. B., Botvinick, M. M., & Norman, K. A. (2017). Complementary Learning Systems within the Hippocampus: A Neural Network Modelling Approach to Reconciling Episodic Memory with Statistical Learning. *Philosophical Transactions of the Royal Society B*, 372(1711), 20160049. https://doi.org/10.1098/rstb.2016.0049

## 摘要

海马体同时支持情景记忆（记住特定事件）和统计学习（从事件中提取规律）。这些功能看似矛盾：情景记忆需要模式分离（为相似事件创建不同的表征），而统计学习需要模式完成（在相似事件之间泛化）。

Schapiro 等人提出，海马体包含**两个互补的子系统**：
- **齿状回 / CA3**：模式分离——创建不同的情景编码
- **CA1 / 下托**：模式完成——在统计相似的事件之间泛化

重放机制在这两个子系统之间进行仲裁，使海马体能够同时支持特异性和泛化。

## 方法论

本文结合了：
1. **计算建模**：一个海马体神经网络模型，具有显式的模式分离（DG）和模式完成（CA1）通路。
2. **人类 fMRI**：参与者学习具有重叠元素的时间序列；海马体活动同时跟踪项目特异性和统计预测。
3. **啮齿动物电生理学**：重放研究的综述，显示重放序列经常偏离实际经验——表明重放不是忠实的回放，而是**结构化的重新评估**。

## 核心发现

### 1. 海马体通过重放解决时间模糊性

当两个事件（A→B 和 A→C）共享一个共同元素（A）时，海马体使用重放来「测试」在当前上下文中哪个延续更可能。这**不是检索**——而是**通过模拟进行因果推断**。

### 2. 重放序列不是忠实的副本

啮齿动物的重放通常包括：
- **反向重放**：事件反向播放（评估后果）
- **新颖序列**：从未经历过的组合（模拟）
- **压缩时间**：数秒的经验在毫秒内重放

这证明重放是**生成性的**，不是再现性的。

### 3. 模式分离与完成是动态调节的

海马体不固定分离/完成的权衡。相反，它根据以下因素动态调整：
- **新颖性**：新颖事件 → 更多分离
- **可预测性**：可预测事件 → 更多完成
- **奖励**：高风险事件 → 更多分离（保留细节）

## 方法论评析

| 优点 | 局限 |
|---|---|
| 计算模型做出可检验的预测 | 模型被简化了；省略了许多生物学细节 |
| fMRI + 建模融合增强了主张 | fMRI 时间分辨率太粗，无法直接观察重放 |
| 成功调和了两个看似矛盾的功能 | 没有解释仲裁机制在算法上如何运作 |

## 与 `causal-memory` 的连接

### 1. 离线巩固作为「压缩重放」

v0.4 路线图包括一个直接受此论文启发的**离线巩固周期**：

```
活跃阶段（16h）：agent 运行，causal_edges 累积
巩固阶段（4h）：「重放」近期因果链
  - 检测矛盾（同一决策 → 相反结果）
  - 合并冗余边（A→B 和 A'→B' 实际上是同一模式）
  - 将高置信度模式提升到 meta_causal_edges
深度维护（4h）：DB 压缩、索引优化
```

这不是隐喻。本文表明，重放对于解决在实时编码期间无法解决的模糊性**至关重要**。

### 2. 基于置信度的分离/完成权衡

我们的置信度层级编码了相同的权衡：
- **高置信度**（0.9+，user_feedback）→ 保留细节（模式分离）
- **低置信度**（0.4，temporal）→ 泛化（模式完成）

未来版本可以动态调整检索：高风险查询获得高分离检索（特定片段）；常规查询获得高完成检索（一般模式）。

### 3. 反向重放 → `trace_cause_chain`

本文发现啮齿动物**反向**重放序列来评估后果，这是我们多跳反向追溯的生物学基础。反向重放是大自然的 `trace_cause_chain`。

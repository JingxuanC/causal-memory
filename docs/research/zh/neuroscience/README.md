## 大图景

大脑不把记忆当作文件柜。它把记忆当作**因果推理系统**：

- **海马体**快速编码离散事件（决策→结果对）
- **离线重放**在休息/睡眠期间重新评估哪些事件实际上是因果关联的
- **前额叶皮层**维持相互竞争的因果假设并解决冲突

`causal-memory` v0.2 只实现了第一步（海马体编码）。本节神经科学论文论证了为什么接下来的步骤（巩固、重放、冲突解决）不是可选功能——它们是**功能性因果记忆系统的必要组成部分**。

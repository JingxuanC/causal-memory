# 长期终态蓝图 —— 一个自演化、压缩免疫的「因果大脑」

> 状态：北星文档（2026-08-20）。定位：本文件描述**最终版本应该长什么样**——不是路线图（roadmap.md），
> 不是架构提案（complete-memory-system.md），不是中期收敛（one-graph-convergence.md），而是这三者的
> **共同终点**：一个可描述、可验证、可写进论文的 end-state。

## 0. 一句话

> **一个嵌入 agent 的单文件因果大脑**：所有记忆是一张 typed 图，一个引擎传播，一个循环巩固；
> 它记住「什么导致了什么」（含阻止了什么），能预测「如果再来一次会怎样」（含危险警示），
> 经验在巩固中沉淀为可迁移的模式；无论上下文被压缩多少次，它都完整存活——
> 而且**是唯一同时拥有兴奋侧和抑制侧的**。

## 1. 终态形态

```
                 ┌────────────────────────────────────────────┐
                 │              THE AGENT'S MEMORY            │
 记录             │                                            │       检索
 record_decision ►│  一张 typed-edge 图（全部记忆类型）          │◄── search_memory（唯一默认入口）
 record_fact ────►│  节点 = 记忆痕迹（fact/情景/时序）           │◄── intervention / counterfactual
 remember ───────►│  边   = caused/enabled/prevented/fact/      │◄── trace_cause / reconstruct
    │             │          co_occurrence/meta + 时间元数据     │
    │  distill    │  一个引擎：typed 激活扩散                    │
    ▼             │  一个循环：不可变 SWR 巩固                    │
    └───────────►  └────────────────────────────────────────────┘
                             ▲                    │
                             │ 巩固（delta+clone）  │ 检索（激活轨迹可解释）
                             └── sleep 周期 ────────┘
```

## 2. 六大终态特征（每项附现状差距）

### ① 一张图统一所有记忆

- 终态：SQLite（真相源，P5 压缩免疫）与内存图（查询表面）用**增量补丁**保持同步；图覆盖全部边类型
  （fact 是一等公民，不是外挂表）；图 = 查询表面，BM25/语义退化为播种层。
- 现状：图只覆盖 causal/meta/cooc，agent_facts 外挂，图是 5 写/30s 懒重建缓存；真实图 207 个孤立分量。
- 路径：one-graph-convergence.md 的 Phase A-D。

### ② 认知闭环（One Loop）

- 终态：自我改进的系统——行动 → 记录 → sleep 巩固（Q 值强化 + 泛化 + REM 迁移）→ 检索播种变强 → 更好的干预预测。
  Q-value 从播种加权演进为**边权重级动力学**（edge-weight variant，等 CausalEval A/B 验证）。
- 验证：Memora 基准（周→季度遗忘维度）把「压缩存活」从一次实验变成持续属性。

### ③ 完整 Pearl 阶梯

- 终态：Rung-3 真 SCM 反事实（当前只有经验对比，诚实标注非 SCM）；干预预测带**模拟**而非仅历史检索；
  三层因果推理全部可解释、带置信与激活轨迹（P4）。

### ④ 独家抑制侧（P1，竞争壁垒）

- 终态：prevented 负扩散作为第一等公民——DANGER 预警贯穿干预/反事实/重构叙事；
  正式消融（去掉 prevented 后预警能力下降的量化）写进论文。
- 现状：机制已实现且 CausalEval C4 90% vs mem0 50%，但无正式消融数字。

### ⑤ 多智能体共享记忆

- 终态：HTTP 共享从雏形进化为实时共写的因果记忆（user_id/租户隔离）；一个 agent 的教训（meta 边）
  成为团队的语义记忆；export/import 只是离线兜底。

### ⑥ 可观察 + 分层 + 预算（P4/OpenViking 模式）

- 终态：检索带激活轨迹（能回答「为什么返回这条」）；L0 目录 / L1 概览 / L2 全文分层加载；
  严格 token 预算（对照 OpenViking 34-91% 节省）；工具收敛为默认三个（search_memory /
  record_decision / trace_cause）+ 专家模式（顶层文档风险清单第一条的对策）。

## 3. 验证标尺（终态达成判据）

| 维度 | 当前 | 终态目标 |
|---|---|---|

## 6. 诚实评估（终态之前必须正视的欠账）

> 本系统当前是优秀的研究原型，尚不是世界级架构。到终态的距离不是「再调调参」，而是：

1. **关联记忆尚未成立**：真实图是 207 个孤立分量——「记忆是关联的」目前是引擎比数据先进。
2. **评测自证风险**：CausalEval 的图和 gold 自生成、答题与评判同模型家族——高分数部分是自洽性，
   需要独立评测（别人跑我们的 bench / 我们跑外部 bench + 第三方消融）。
3. **规模与生态**：无百万边规模证明、无第三方大规模采纳、无正式论文。
4. **竞争差异可持续性**：抑制侧是别人抄起来要重写核心的差异化，但需要持续用消融和 benchmark 捍卫。

## 7. 一句话收尾

终态不是「更多的表、更多的工具」，而是**收敛**：一张图、一个引擎、一个循环、三个默认工具、
一组可验证的数字。它是这个项目能讲给世界的完整故事——因果记忆 + 抑制 + 压缩免疫。
